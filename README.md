The plan for what to build, and what to leave out, is in [PLAN.md](PLAN.md). The validated Cloudflare exercise, kept separate from those pages, is in [docs/architecture.md](docs/architecture.md) and [platform/README.md](platform/README.md).

```
index.html          entrance
background.html     background
learning.html       current learning
contact.html        contact form
styles.css          shared layout
script.js           navigation state
contact.js          form submit
platform/           gateway, content, and inquiry services
```
